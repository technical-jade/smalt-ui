`SButton` with `variant="link"` answers hover with color: the text shifts 30% toward `--s-shade`, so it gets darker in the light theme and lighter in the dark one, and a link with `color="neutral"` takes the accent color. The underline does not change. A button with `color="neutral"` gets the new `.s-button--neutral` modifier class.
